## 2. What is JavaScript?

## 3. What three problems does Git & GitHub solve?

To collaborate on code without confusion, track history/changes, and prevent data loss when working in a team.

## 4. What happens when you `fork` a repository?

The process of copying a repository to your own GitHub account.

## 5. What happens when you clone a repository?

Downloading a remote repository to your local machine to work on it locally.

## 6. What is a Pull Request?

A request to merge your code changes into the main project after review by a mentor or team leader.
